# Project: DevfinityFrontend

## Vision
A modern, dynamic portfolio and marketing website to showcase projects, skills, and services.

## Production Domain
- **Official URL:** `https://devfinity.net` (Canonical for all SEO, metadata, sitemaps, robots.txt, and JSON-LD schemas).

## Tech Stack
- Framework: Next.js 16 (App Router, Turbopack)
- UI Library: React 19
- Styling: Tailwind CSS 4
- 3D & Graphics: Three.js WebGL procedural studio canvas
- Components: shadcn/ui
- Icons: Lucide React

## Goals
- Create a visually stunning and responsive portfolio with "Light Mode Plus" glassmorphism.
- Ensure top-tier SEO and Generative Engine Optimization (AIO/GEO) ranking.
- Enterprise security compliance (CSP, HSTS, Consent Mode v2, UTM tracking).
